MyLingo – AI Web Page Translator

A Chrome extension that translates the web page you are viewing — or just the text you select — into the language you want, using the AI service you choose: ChatGPT (OpenAI), Claude (Anthropic) or Gemini (Google). Pages keep their layout, and you can switch back to the original in one click.

  • Uses your own API key. Your text goes straight from your browser to the service you choose.
  • No MyLingo server, no analytics, no tracking, no ads.
  • A free Gemini API key from Google AI Studio is enough to get started.

How it works

  1. Enter an API key for OpenAI, Anthropic or Google Gemini on the extension’s settings page.
  2. Click the toolbar icon and press “Translate this page”. What is on screen is translated first, and the rest as you scroll.
  3. Press “Show original” or Alt+Shift+T to switch back. To translate just a part, select text, right-click and choose “Translate … with MyLingo”.

Features

  • Switch between ChatGPT, Claude and Gemini, and set the model for each.
  • Translate into English, Japanese, Chinese, Korean, Spanish, French, German and many more, or type any language.
  • Five translation modes: Faithful, Natural, Business, Casual & social, Technical.
  • API keys can be encrypted with a passkey (Touch ID, etc.) or a passphrase.
  • The interface is available in English and Japanese.
