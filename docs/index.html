FAQ

Questions and answers

Is Langria free?

Yes. The extension and the apps are free. Translations are made with your own API key, so any usage charges come from the AI service you choose, and Gemini’s free tier is enough to get started. The extension and the web app have no ads; the iOS and Android apps show a banner ad, which never sees the text you translate.

What is an API key, and where do I get one?

An API key lets Langria use an AI service on your behalf. Get one from Google AI Studio (Gemini, free tier available), OpenAI or Anthropic. Until a key is saved, Langria shows you where to get one.

What happens to my text?

It is sent directly from your browser or device to the AI service you chose, only when you ask for a translation. Langria has no server of its own, and there are no analytics in the extension or the apps. Photos are read on the device, and only the recognized text is sent. API keys can be encrypted with a passkey (Touch ID, etc.) or a passphrase, or locked with Face ID or your fingerprint on mobile. See the privacy policy for details.

Which languages are supported?

English, Japanese, Chinese, Korean, Spanish, French, German and many more are in the list, and you can type the name of any other language. Langria’s own interface is available in English and Japanese.

Can I host the web app myself?

Yes, and we recommend it for regular use: the web app on this site is a demo. It is a static site with no build step, so you can put the files from the GitHub repository on any web server or run it on localhost. It is also available as a container image of about 1 MB: run docker run --rm -p 8080:8080 ghcr.io/shigeya-t/langria and open http://localhost:8080. See the README.

Can I install the extension from the source code?

Yes. Download or clone the GitHub repository, open chrome://extensions, turn on “Developer mode”, click “Load unpacked” and select the extension folder. It is not updated automatically: after pulling new code, press Langria’s reload button (↻). See the README for details.
