iPhone · iPad · Apple Watch · Android

撮って、話して、手首でも。

旅先の看板やメニューを撮る、スマホに話しかける、ほかのアプリから文章を共有する。日常のあらゆる場面で数秒で翻訳します。

  • 写真の文字認識（OCR）は端末内で完結。送るのは文字だけで、画像は送りません。
  • 音声入力と訳文の読み上げに対応。会話のキャッチボールにも。
  • iPhone は共有シート・Siri・ショートカット、Android は共有・文字選択メニューから直接翻訳。
  • Apple Watch 単体でも、手首だけでサッと翻訳できます。

FAQ

よくある質問

無料で使えますか？

はい。拡張機能とアプリは無料です。翻訳にはご自身のAPIキーを使うため、利用料がかかる場合は選んだAIサービスから請求されます。Gemini の無料枠でも始められます。拡張機能とWebアプリに広告はありません。iOS・Androidアプリにはバナー広告が出ますが、翻訳する文章が広告に使われることはありません。

APIキーとは何ですか？どこで取得できますか？

Langria がAIサービスを使うための鍵です。Google AI Studio（Gemini。無料枠あり）、OpenAI、Anthropic で取得できます。キーを保存するまでは、Langria の画面に取得先が案内されます。

翻訳する文章はどう扱われますか？

翻訳を頼んだときだけ、ブラウザや端末から選んだAIサービスへ直接送られます。Langria 独自のサーバーはなく、拡張機能やアプリにアクセス解析もありません。写真の文字は端末内で読み取り、送るのは文字だけです。APIキーはパスキー（Touch ID など）やパスフレーズで暗号化でき、スマホでは Face ID や指紋でロックできます。詳しくはプライバシーポリシーをご覧ください。

どの言語に翻訳できますか？

英語・日本語・中国語・韓国語・スペイン語・フランス語・ドイツ語など多数の言語を一覧から選べ、一覧にない言語も名前を入力して指定できます。Langria の画面は日本語と英語で表示できます。

Webアプリを自分のサーバーに置けますか？

はい。このサイトのWebアプリはお試し用のデモなので、普段使いにはご自身の環境に置くことをおすすめします。ビルド不要の静的サイトなので、GitHub のリポジトリのファイルを好きなWebサーバーに置くか、localhost で開くだけで使えます。1 MB ほどのコンテナイメージもあり、docker run --rm -p 8080:8080 ghcr.io/shigeya-t/langria を実行して http://localhost:8080 を開くだけでも使えます。手順は README をご覧ください。

拡張機能をソースコードから入れられますか？

はい。GitHub のリポジトリをダウンロード（または clone）し、chrome://extensions で「デベロッパーモード」をオンにして、「パッケージ化されていない拡張機能を読み込む」で extension フォルダを選びます。自動では更新されないので、新しいコードを取り込んだら Langria の再読み込みボタン（↻）を押してください。詳しくは README をご覧ください。

さっそく、言葉の壁なく読んでみませんか

Langria は無料。Gemini の無料キーがあれば、1分もかからず最初のページを翻訳できます。
