プライバシーポリシー

最終更新日: 2026年10月21日

このポリシーは、Chrome拡張機能「Langria – AI Webページ翻訳」、Langria のWebアプリ、Langria のiOSアプリが利用者のデータをどう扱うかを説明するものです。Langria は独自のサーバーを持たず、開発者が利用者のデータを受け取ったり、収集・保存したりすることはありません。

  • 文章は、翻訳を指示したときにだけ、利用者が選んだAIサービス（OpenAI・Anthropic・Google）へ送信されます。
  • APIキーと設定はブラウザ内にだけ保存されます。APIキーはパスキーまたはパスフレーズで暗号化できます。
  • 拡張機能とWebアプリには、アクセス解析・トラッキング・広告はありません。iOSアプリは Google AdMob の広告を表示しますが、翻訳する文章を広告に使うことはありません。
  • データを販売することはありません。

扱うデータ

  • Webサイトのコンテンツ: 翻訳するページの文章、または選択して右クリックメニューから翻訳する文章。翻訳を始めたとき（ツールバーのポップアップ、右クリックメニュー、キーボードショートカット）から読み取ります。ページを翻訳している間は、後から追加された文章も読み取り、画面に入った部分から順に送信します。原文に戻すかページを再読み込みすると止まります。
  • APIキー: 利用者が入力した OpenAI・Anthropic・Google Gemini のAPIキー。
  • 設定: 選択中のサービス、モデル名、翻訳先の言語、翻訳モード、リクエスト数の上限、表示言語。
  • 写真（iOSアプリ）: 文字を翻訳するために撮影した写真や、選んだ写真。文字の読み取りは端末の中（Apple の Vision）で行い、画像は送信も保存もしません。翻訳のために送るのは、読み取った文字だけです。
  • 音声（iOSアプリ）: 音声入力のボタンを押している間の、マイクの音声。Apple の音声認識で文字にします。言語が端末内の認識に対応していれば端末の中で処理し、対応していなければキーボードの音声入力と同じく Apple へ送られます（Apple のプライバシーポリシー）。Langria は音声を保存せず、AIサービスへ送るのは文字だけです。訳文の読み上げは端末の中で行います。

閲覧履歴、個人情報、位置情報などそのほかのデータは収集しません。

データの送信先

翻訳するとき、翻訳する文章は利用者自身のAPIキーを使って、ブラウザから選択したサービスへ直接送信されます。

  • ChatGPT: OpenAI（api.openai.com）— OpenAI のプライバシーポリシー
  • Claude: Anthropic（api.anthropic.com）— Anthropic のプライバシーポリシー
  • Gemini: Google（generativelanguage.googleapis.com）— Google のプライバシーポリシー、Gemini API 利用規約

送信した文章がそのサービスでどう扱われるか（保存期間や学習への利用など）は、各サービスの規約と利用者のアカウント設定によります。機密性の高い文章を翻訳する前にご確認ください。iOSアプリの広告（後述）を除き、Langria がこれ以外の送信先へデータを送ることはありません。

shigeya-t.github.io/Langria/app/ で公開しているWebアプリは GitHub Pages で配信し、フォントを Google Fonts から読み込みます。一般的なWebサイトと同じく、ページを開いたときに IPアドレスやブラウザの情報が GitHub と Google に送られますが、翻訳する文章やAPIキーは送られません。詳しくは GitHub のプライバシーステートメントと Google Fonts のプライバシーに関する FAQ をご覧ください。

広告（iOSアプリ）

iOSアプリは、ページの最後（翻訳欄の下）に Google AdMob のバナー広告を表示します。Chrome拡張機能とWebアプリには広告はありません。

  • Google の Mobile Ads SDK は、広告の配信と効果測定のために、IPアドレス、端末の機種、OS のバージョン、広告の表示やタップ、そしてトラッキングを許可した場合にだけ広告識別子（IDFA）などの端末・利用状況のデータを収集します。詳しくは Google のサービスを使用するサイトやアプリから収集した情報の Google による使用と Google のプライバシーポリシーをご覧ください。
  • 翻訳する文章、翻訳結果、APIキー、写真、音声を広告に渡すことはありません。
  • アプリはトラッキングの許可（App Tracking Transparency）を求めます。許可しなければ、広告識別子を使ったパーソナライズは行われません。許可はいつでも iPhone の「設定」→「プライバシーとセキュリティ」→「トラッキング」で変えられます。
  • 法律で必要な地域（EEA・英国・スイスなど）では、最初に Google の同意フォームを表示します。選んだ内容は、アプリの設定の「広告のプライバシー設定」から後で変えられます。

保存

  • 拡張機能は、APIキーと設定を端末内の chrome.storage.local に保存します。Google アカウントには同期されません。
  • APIキーの暗号化を有効にすると、キーは暗号化された形（AES-GCM）でだけ保存されます。ロックを解除したあと、復号したキーはブラウザを閉じるまでメモリ上（chrome.storage.session）に保持されます。
  • サービスが1分あたりのリクエスト数の上限を知らせてきた場合（Gemini の無料枠など）、リクエストの間隔を空けるため、その上限の数をブラウザを閉じるまで chrome.storage.session に保持します。
  • 翻訳結果は保存しません。ページ上に表示し、原文に戻したときやページを離れたときに破棄されます。
  • Webアプリは、同じ種類の設定をブラウザの localStorage に保存します。
  • iOSアプリは、APIキーをこの端末のキーチェーン（ほかの端末へ同期しない項目）に、設定を端末内（UserDefaults）に保存します。ロックをオンにすると、キーチェーンのキーを読み出すたびに Face ID・Touch ID またはパスコードが必要になり、解除したキーはアプリが背面に回るまでメモリ上にだけ保持します。

権限

  • activeTab・scripting: 翻訳するタブの文章を読み取り、翻訳文に差し替えるため。そのタブで翻訳を指示したときにだけ使います。
  • storage: APIキーと設定を端末内に保存するため。
  • contextMenus: 右クリックメニューに「Langria で翻訳」を追加するため。
  • api.openai.com・api.anthropic.com・generativelanguage.googleapis.com へのアクセス: 選択したサービスへ翻訳のリクエストを送るため。
  • iOSアプリのカメラ: 文字を撮影して翻訳するため。撮影を選んだときにだけ使います。写真ライブラリはシステムの写真ピッカーで選んだ写真だけを受け取り、ライブラリ全体へのアクセスは求めません。Face ID は APIキーのロックを解除するときにだけ使います。
  • iOSアプリのマイクと音声認識: 音声入力のボタンを押したときにだけ使います。
  • iOSアプリのトラッキング: 広告識別子で広告をパーソナライズするために一度だけ求めます。許可しなくても、アプリは同じように使えます。

データの利用目的

データは、Langria の唯一の目的である翻訳のためにだけ使います。販売、選択したAIサービス以外の第三者への提供、広告への利用（上記のiOSアプリの広告にも渡しません）、信用力の判断や融資目的での利用は行いません。Chrome の API から得た情報の利用は、限定利用（Limited Use）の要件を含む Chrome ウェブストアのユーザーデータに関するポリシーに従います。

データの削除

拡張機能の設定画面でAPIキーを消すか、chrome://extensions から拡張機能を削除してください。削除すると、拡張機能が保存したデータはすべて消去されます。Webアプリの場合は、ブラウザでそのアドレスのサイトデータを削除してください。iOSアプリの場合は、設定画面でAPIキーを消すか、アプリを削除してください。AIサービス側に残るデータの削除は、各サービスのアカウント設定から行ってください。

子どもについて

Langria は子ども向けのサービスではなく、子どもの情報を意図して収集することはありません。
